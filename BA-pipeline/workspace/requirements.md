## 3. Yêu Cầu Phi Chức Năng (Non-Functional Requirements - NFRs)
- **NFR-SEC-01**: Mã hóa mật khẩu BCrypt, hỗ trợ SSO / VNeID OAuth2, kiểm soát phân quyền RBAC đến từng API endpoint.
- **NFR-PERF-01**: Thời gian phản hồi API tra cứu < 1.5s đối với 95% số request dưới tải 500 CCU.
- **NFR-AVAIL-01**: Mức độ sẵn sàng của hệ thống Uptime >= 99.5%/năm.
- **NFR-BCK-01**: Sao lưu CSDL tự động hàng ngày (Full backup lúc 00:00, RPO < 24h, RTO < 2h).
