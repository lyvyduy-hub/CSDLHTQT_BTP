# Đánh Giá Đầu Vào & Phân Tích Phạm Vi (Input Assessment)

## 1. Thông Tin Tài Liệu Nguồn Khách Hàng Cung Cấp
- **Dự án xây dựng CSDL Hợp tác quốc tế.xlsx**: Chứa danh mục chức năng (DSCN & DSCN_TKCT_final) với 89 chức năng chi tiết phân làm 2 ứng dụng lớn (Web Admin & Web Portal/Cổng thông tin) cùng 6 phân hệ nghiệp vụ chính. Chứa các đường link tài liệu Figma, thiết kế CSDL, quy định chung.
- **CSDLHTQT_Thiết kế CSDL.xlsx**: Chứa cấu trúc 23 bảng CSDL vật lý (RESOURCES, ROLE, SYS_USER, ORG, INTERNATIONAL_AGREEMENT, EXPERT, CONFERENCE, DELEGATION, PROJECT_PROGRAM, DOCUMENT, DATA_SHARING_CONNECTION...), tên cột, kiểu dữ liệu, khóa chính/ngoại, mô tả tiếng Việt.
- **CSDL HTQT_Quy định dùng chung.xlsx**: Chứa các quy định dùng chung về thiết kế UI/UX (Mã D012 - D018: Upload file đính kèm, tải file đính kèm, tab tài liệu, xóa file, danh sách hoạt động, lọc thời gian báo cáo) và quy định dữ liệu.

- **Mô hình phân phối nền tảng**: Tài liệu xác định rõ phạm vi đợt này là **Web App Responsive** (Web Admin + Web Portal). Không triển khai app mobile native riêng cài qua App Store/Google Play trong phạm vi đợt 1.
- **Liên thông dữ liệu**: Các API chia sẻ dữ liệu được thực hiện thông qua Nền tảng kết nối chia sẻ dữ liệu Bộ Tư pháp (LGSP) và Kho dữ liệu dùng chung.
