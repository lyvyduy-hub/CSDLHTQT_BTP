# Điều Lệ Dự Án (Project Charter) — CSDL Hợp Tác Quốc Tế

## 1. Thông Tin Tổng Quan Dự Án
- **Tên dự án**: Xây dựng CSDL Hợp tác quốc tế về pháp luật và tư pháp - Bộ Tư pháp.
- **Mã dự án**: CSDLHTQT
- **Đơn vị chủ quản**: Bộ Tư pháp (Vụ Hợp tác quốc tế)
- **Đơn vị triển khai**: Ban dự án CNTT & Đội ngũ Phát triển

## 2. Mục Tiêu Dự Án
1. Số hóa toàn bộ quy trình quản lý hoạt động hợp tác quốc tế: Điều ước quốc tế, Thỏa thuận quốc tế, Chương trình/Dự án, Hội nghị/Hội thảo, Đoàn ra/Đoàn vào, Chuyên gia, Khen thưởng.
2. Cung cấp Cổng thông tin điện tử CSDL Hợp tác quốc tế phục vụ khai thác, tra cứu công khai và nội bộ.
3. Tích hợp liên thông dữ liệu với CSDL Pháp luật quốc gia, Kho dữ liệu dùng chung Bộ Tư pháp, Nền tảng kết nối chia sẻ LGSP, QLVB&ĐH, VNeID.

## 3. Mô Hình Phân Phối Nền Tảng (Platform Delivery Model)

| Deliverable | Loại | Nền tảng cụ thể | Phân phối qua | Chạy trên thiết bị |
|---|---|---|---|---|
| Web app Admin | Responsive web (trình duyệt) | HTML5 / CSS3 / React / Vue / Next.js | URL trực tiếp nội bộ | Desktop, Tablet (browser), Mobile (browser) |
| Web Portal | Responsive web (trình duyệt) | HTML5 / CSS3 / Web Portal | URL trực tiếp công khai | Desktop, Tablet (browser), Mobile (browser) |

*Ghi chú*: Dự án không xây dựng Mobile App native phân phối qua App Store / Google Play trong giai đoạn này.

## 4. Phạm Vi Dự Án (Scope In / Scope Out)
- **Scope In**: 89 chức năng nghiệp vụ (Quản trị hệ thống, Quản lý tài khoản, Quản lý nghiệp vụ HTQT, Đồng bộ dữ liệu, Danh mục hệ thống, Báo cáo thống kê, Tích hợp LGSP).
- **Scope Out**: Xây dựng ứng dụng di động Native iOS/Android; Xây dựng hạ tầng cơ sở dữ liệu vật lý riêng ngoài Trung tâm dữ liệu Bộ Tư pháp.
